# 原版单机模式（2026-10-07）

## 使用

双击项目中的 `start-solo.bat`，或者从首页及模式导航选择「原版单机」。入口是 `web/solo.html`。原有 `start.bat` 本地双人、局域网和公网入口保持可用。

点击「开始单机游戏」后正常播放原版开头、进入标题菜单，由玩家在游戏中选人、选择机体并开始。触屏菜单提供上下左右、确认、Bomb 返回与 ESC；游玩中使用拖动移动、低速、开火切换及可选双击 Bomb。没有救援按钮。

「低速显示判定点」与「触摸模式一直显示判定点」在启动页同一设置组中；后者仅在触屏操作启用时生效。「按键与触控」中仍可配置触控布局、灵敏度和不限速移动。单机键盘/手柄绑定与低速判定点偏好有独立 solo 配置。原版菜单的游戏设置与记录在本次运行中有效，重新启动/刷新加载干净磁盘，不做跨次磁盘存档。

## 与合作模式隔离

- 单独的 `solo.js`、`th04-solo.hdi.gz`、`solo-patch.json`，不加载合作磁盘、COOP.COM、开局配置注入、合作 HUD 或联网运行时。
- 从经过 SHA-256 验证的 baseline 构建。文件清单保持相同：只替换 `GENSO/MAIN.EXE`，其余 31 个文件逐字节一致，包括 AUTOEXEC.BAT、GAME.BAT、OP.EXE、MAINE.EXE、音乐及游戏数据。
- MAIN 只加入 704 字节适配，六个 near-call 挂钩用于原生触摸速度、可选判定点及状态通知。原 320000 字节资源堆不变。MAIN 的其他差异仅为插入段所需的 MZ 重定位与尺寸更新。
- 没有多人银行、伤害/Power/分数倍率、共享资源、救援、合作瞄准或跳关功能。原函数在适配后照常调用。
- 吸引演示模式不应用触摸移动/判定点。暂停、切关和世界退出清除待消费位移；阻塞菜单/对话停止更新时网页回到菜单控制。菜单触屏按键保留短暂按下时间，兼容 DOS 菜单自身的轮询。

## 构建与验证

在仓库上层运行：

```powershell
python th04-coop-lab/tools/build_solo.py
python th04-coop-lab/tools/test_solo_cpu.py
python th04-coop-lab/server.py --no-browser --port 9886 --page solo.html
node th04-coop-lab/tools/test_solo_browser.cjs
```

原生构建需要本地 baseline、NASM 和原有 touch.asm。浏览器测试可用 `PLAYWRIGHT_MODULE` 与 `BROWSER_EXE` 指定本机工具路径。

已验证：

- 对磁盘所有文件进行隔离审计；撤销声明的六个补丁、插入段及重定位后，MAIN image 与原版逐字节一致。
- Unicorn 执行实际 16 位指令：原作速度/低速、不限速、坐标边界、未触控时保留键盘移动，以及低速/常显/受击/入场/演示的判定点绘制条件。
- Edge 移动触屏模拟：完整原版开头和标题、通过触屏确认选择进入第一关、实际改变原生角色坐标、原版暂停/继续、两个判定点开关及原版退出关卡流程。
- 共享播放器原有触屏回归、触屏数据传递和回滚队列测试通过。JS/Python 语法检查通过。
