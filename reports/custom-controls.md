# 自定义操作

2026-10-04。新增代码未运行测试、浏览器或游戏，由用户人工试玩。

## 使用

本地 `index.html` 和联机 `lan.html` 都有「自定义操作」按钮，开局前或游戏中均可打开。游戏中请先暂停，编辑面板只阻止自己的输入，不会自动暂停关卡。

- 本地 P1 / P2 与联机当前玩家的设置独立；联机选择任何座位都使用自己的联机配置。
- 点击键位按钮，再按新键。Esc 取消录入；「设为 Esc」用于将动作绑定至 Esc。「清除」取消该动作的键盘绑定。
- 同一配置或同机两位玩家不能使用重复键。冲突时保持原绑定，先清除旧绑定再分配。
- 本地 P2 和联机支持手柄按钮下拉选择，左摇杆仍控制移动；非标准手柄应先切换 XInput 模式。不会更改浏览器安全上下文对手柄的限制。
- 「恢复当前默认」只修改当前操作对象，点击「保存」才生效。「取消」丢弃本次编辑。
- 设置保存在当前浏览器、当前网址的 localStorage。不同地址/端口、其他浏览器不会共享。浏览器拒绝保存时显示提示，本页面仍可使用，刷新后不保证保留。
- 默认本地 P2 无独立键盘暂停/确认，可以自行设置；手柄默认 Start 暂停。移动、射击、低速等默认键维持原样。

## 实现边界

`control-settings.js` 负责配置校验、动作映射和 UI。默认保留左右 Shift 两个绑定，手动重新绑定会替换该动作全部旧键。每个动作可绑定一个新物理键，不支持宏或组合快捷键；物理键可同时按住进行斜向移动、低速射击。手柄按钮索引 0–31 可选，-1 表示无绑定，不提供摇杆轴重映射。

联机父页与游戏 iframe 显式同步当前配置，编辑阻止标志不进入游戏状态；网络、暂停权限、回滚仍消费原来的逻辑操作位。父页清空按键，iframe 清空自身按键；重绑定不修改已入队的历史帧。共用模块纳入原有 controls 指纹，不把个人配置放入版本比较。

单机 P1 在 WASM 启动前注册捕获监听器，将物理键翻译为原生按键，带 WeakSet 标识的合成事件可穿过捕获层。P2 继续写 mailbox，暂停/确认转换为原生菜单按键。丢焦、切到表单、打开设置均释放按键，P2 手柄断开时返回零输入。
