# TH04 双语单机与双人／三人合作实验

基于 NP21 WASM 运行《东方幻想乡》，提供可选汉化／日文的独立单机、本地双人和双人／三人网络合作。当前版本：2026-10-08，联机协议 `th04-rollback/3`。

本仓库上传的是可直接运行的版本：包含网页、游戏资源、服务器和启动器，不需要构建工具。开发源码、基线磁盘和测试报告仅保留在维护者本地。

## 启动

需要 Python 3，并使用支持 WebAssembly、gzip 流解压的现代浏览器。使用随附运行资源即可游玩，无需先重建游戏磁盘；请通过启动器访问，不要直接双击 HTML。

| 模式 | 启动方式 | 说明 |
| --- | --- | --- |
| 单机游戏 | `start-solo.bat` | 打开 `solo.html`，保留原版开头和菜单 |
| 本地双人 | `start.bat` | 打开 `local.html`，一台设备控制两位玩家 |
| 局域网联机 | `start-lan.bat` | 默认端口 9866，伙伴打开启动窗口提供的网址 |
| 公网联机 | 部署房间服务后打开 `lan.html?network=public` | 支持 WebRTC 直连，也可选 WebSocket 转发 |

本地单机／双人服务器仅监听本机，默认端口 9864，被占用时向后寻找可用端口。手机访问请使用局域网服务器的网址，再从导航进入所需模式。

网络房间由房主设置人数、难度等；玩家先落座，再选择自己的机体，全部准备后由房主开始。更新版本后重启服务，所有端刷新并重新建房；已启动的游戏不会自动替换运行文件。

临时公网测试：先运行 `install-relay.bat` 安装转发依赖，并安装可从 PATH 调用的 `cloudflared`；保持 `start-lan.bat` 运行，再启动 `start-public-tunnel.bat`。连接建立后分享窗口显示的完整游戏链接，也可从 `public-test-url.txt` 读取。Quick Tunnel 重启会换地址，网址文件不能证明隧道仍在线。

部署与排障见 [局域网说明](LAN-试玩说明.md) 和 [公网转发说明](README-RELAY.md)。

## 单机与游戏语言

单机、本地双人和网络合作均可选择“汉化版”或“日文版”，默认汉化版。两版都保留各模式现有补丁：单机的触控与判定点，以及合作模式的机体、资源、救援、计分等魔改。语言选项改变游戏内容，网页操作界面仍为中文。

单机和本地双人在启动前选择语言，并分别保存在当前浏览器；游戏启动后需重新启动才能切换。网络房间由房主在“本局设置”选择，全员自动使用同一语言；切换后所有玩家重新准备，开局后锁定。

汉化版基于 `4-cn.hdi.gz`，日文版基于原有 `4-jp.hdi.gz`。分发包已包含构建好的磁盘，玩家无需另行下载源盘。

单机使用独立的 `web/th04-solo.hdi.gz`（汉化）或 `web/th04-solo-jp.hdi.gz`（日文），保留原版开头、标题、选人、关卡与暂停流程，不加载合作玩法或房间运行时。原生补丁只接入触摸移动和可选判定点显示。

当前磁盘写入只保留在本次运行，刷新／重启会恢复初始磁盘。

## 操作与触屏

键盘、手柄绑定可在“自定义操作”中调整并保存到当前浏览器。本地 P1 默认方向键、Z 射击、X Bomb、Shift 低速；P2 默认 WASD、J 射击、L Bomb、K 低速。单机和联机默认使用 P1 键位，联机控制自己所选的座位。

触屏采用 TH06 风格布局，支持横竖屏分别保存自定义布局：

- 单指拖动移动，第二指按住低速；开火按钮切换持续射击。
- “双击同一位置使用 Bomb”为可选开关，也可直接点击 Bomb 按钮。
- “触摸不限速移动”为可选开关，支持调节灵敏度。
- “低速显示判定点”和“触摸模式一直显示判定点”放在启动页同一组设置中，分别开关。设置保存在当前浏览器；联机判定点在浏览器画面层绘制，开关只改变自己的画面，不进入同步输入或回滚状态。低速开关控制低速玩家的判定点，触摸常显开关仅在本机触摸模式启用时生效。
- 暂停、确认和方向按钮适配原版菜单；“按键与触控”可在沉浸布局中打开。

**Esc 暂停／继续**，P 是备用键，屏幕左上角也有“暂停”按钮。键鼠模式进入原生全屏时会申请仅锁定 Esc；浏览器不支持或不允许锁定时，改用铺满网页的布局，避免 Esc 被全屏接口占用。此时可用 F11 切换浏览器全屏，右上角全屏按钮可退出游戏布局。触控模式保留原生全屏和独立暂停／退出按钮。浏览器可能仍保留长按 Esc 强制退出的行为。旧的默认 Esc 单键配置会在 P 未被占用时补上 P，自定义暂停键保持不变。

操作设置不会自动暂停游戏，请先暂停再改。浏览器可能不允许客机由远端开局事件触发系统全屏，此时使用铺满网页的布局，也可主动点击全屏按钮。

## 合作与联机

合作模式包含独立机体、资源、射击、Bomb、幽灵与救援；网络房间可选两人或三人。房主身份与座位独立。全员可暂停／继续，只有房主能确认退出整局。

联机各端运行自己的模拟器并交换输入，不传输游戏画面。房间“本局设置”提供“启用回滚”开关，默认关闭（局域网、公网和转发均一致），只有房主能在开局前修改；客机只读并自动跟随，修改后全员需重新准备，开局后锁定。开启时优先降低操作等待，关闭时使用确认锁步以减少预测／重算负担，但网络延迟更明显。默认设备直连开启、WebSocket 转发关闭，房主可自行调整。房主掉线会结束本局，客机确认离线后转为离线幽灵，剩余玩家可继续；暂不支持断线重连或主机迁移。

合作计分已修复固定奖励误读寄存器、导致 P1 分数突然封顶为全 9 的问题。更新后需刷新并重开游戏。

## 帧率与性能

单机、本地合作、联机统一使用 **60 Hz 画面更新上限**。原版游戏时钟及联机补步、回滚时序保持不变；设备性能不足时仍可能低于 60 FPS。

当前优化包括缓存 NP21 静态函数表查询、复用已验证的输入内存地址、分段搜索、减少隐藏诊断刷新，以及缓存触摸画面尺寸。同一台电脑第一关持续开火的单次对照中，模拟器平均更新耗时从约 12.6 ms 降至 9.1 ms，减少约 28%；这不是手机上的帧率保证。

已通过单机流程、触摸操作、本地合作启动，以及真实 NP21 优化前后的状态校验和与回滚重放对照。尚未完成手机真机性能对照、完整通关及全部 Boss 特殊碰撞适配，也不能据此宣称真实多端网络已全面验收。

## 上传与更新

沿用 `.gitignore` 的根目录白名单，只分发可直接运行的文件：

- `web/` 中的页面、样式、运行脚本、音乐、字体、模拟器 JS/WASM、许可证和版本清单。
- 四张已打补丁的运行磁盘：`web/th04-solo.hdi.gz`、`web/th04-coop.hdi.gz` 为汉化版；`web/th04-solo-jp.hdi.gz`、`web/th04-coop-jp.hdi.gz` 为日文版。合作磁盘由本地双人和联机共用。无需附带未打补丁的原始磁盘或旧音乐实验磁盘。
- 根目录白名单中的启动器、服务端模块、转发依赖清单和使用说明。

`web/game-version.js` 和 `web/netplay/collision-points.js` 分别用于语言版本选择及本机判定点显示，均为必要运行脚本。四张磁盘、两种语言对应的 `disk*.json`、`patch*.json`、`solo-patch*.json` 及 `web/netplay/runtime.json` 应成套更新；音乐、字体和模拟器由两种语言共用，无需复制。

`start-lan.bat` 直接启动房间服务，不再调用构建器。下载者安装 Python 后即可启动；使用 WebSocket 转发时另运行 `install-relay.bat` 安装依赖。临时公网隧道还需要 cloudflared。

维护者应在本地完成构建，再一起更新已生成的磁盘、适配器和清单，避免混用不同版本。`tools/`、`patches/`、`reports/`、`build/`、`baseline/`、`extracted/`、参考源码、编译器、截图和备份均留在本地；上传包不能用于从源码重建。

打包使用更新提交后的 GitHub 源码压缩包或 `git archive`。直接压缩维护目录不会应用 `.gitignore`，会把本地开发文件一并带上。提交前检查 `git status --short` 和 `git ls-files -ci --exclude-standard`；后者应无输出，因为已跟踪文件不会被新忽略规则自动排除。

本机 TURN 配置、临时公网网址和缓存不上传。忽略或取消跟踪这些文件不会删除维护者的本地副本。
